async function transaction(callback) {
  const client = await pool.connect();
  try {
    await client.query('BEGIN');
    const result = await callback(client);
    await client.query('COMMIT');
    return result;
  } catch (error) {
    await client.query('ROLLBACK');
    throw error;
  } finally {
    client.release();
  }
}

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| hipages.com.au → Scraper | External website, untrusted HTML input |
| Scraper → PostgreSQL | Trusted service (internal network) |
| Environment variables | HIPAGES_USERNAME, HIPAGES_PASSWORD must be secured |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-4-06 | Spoofing | hipages.com.au credentials | mitigate | Store in .env with 600 permissions, never log credentials. Rotate password every 90 days. |
| T-4-07 | Tampering | Lead data from hipages | mitigate | Sanitize all extracted text (trim, remove special chars). Use parameterized queries for inserts. CHECK constraint on status enum. |
| T-4-08 | Denial of Service | Concurrent scraper runs | mitigate | File-based lock prevents overlapping runs. Cron limits to 4x/day. Docker resource limits (CPU: 1, memory: 1G). |
| T-4-09 | Information Disclosure | Database credentials in logs | mitigate | Never log DATABASE_URL. Use connection pool (password in env var, not code). |
| T-4-10 | Tampering | SQL injection via lead fields | mitigate | All inserts use parameterized queries ($1, $2...). No string concatenation in SQL. |
| T-4-11 | Elevation of Privilege | Docker container escape | mitigate | Run as non-root user (scraper). No volume mounts except /app/output. Minimal system packages. |
</threat_model>
