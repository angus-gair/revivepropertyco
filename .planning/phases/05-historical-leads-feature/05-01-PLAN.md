**Type:** `checkpoint:decision`

**Decision:** Choose pagination approach based on hipages.com.au behavior

**Context:**
Must determine how hipages loads additional leads before implementing extraction logic. Different approaches require different Playwright strategies.

**Investigation Steps:**

**Options:**

<details>
<summary><b>Option A: Infinite Scroll</b> (Likely - modern SPA pattern)</summary>

**Pros:**
- Most common pattern for modern web apps
- Can automate with `page.evaluate()` scrolling
- Can control scroll speed for politeness

**Cons:**
- Harder to detect completion (no clear "end" signal)
- May trigger rate limiting if too aggressive
- Need to detect "no more results" condition

**Implementation:**
```javascript
// Scroll to bottom repeatedly until no new content loads
let previousHeight = 0;
let scrollAttempts = 0;
const MAX_SCROLL_ATTEMPTS = 50; // Safety limit

while (scrollAttempts < MAX_SCROLL_ATTEMPTS) {
  // Scroll to bottom
  await page.evaluate(() => {
    window.scrollTo(0, document.body.scrollHeight);
  });

  // Wait for new content to load
  await page.waitForTimeout(2000); // 2 second delay (polite)

  // Check if page height changed (new content loaded)
  const currentHeight = await page.evaluate(() => document.body.scrollHeight);
  if (currentHeight === previousHeight) {
    console.log('[scraper] No more content to load');
    break;
  }

  previousHeight = currentHeight;
  scrollAttempts++;
}
```
</details>

<details>
<summary><b>Option B: "Load More" Button</b></summary>

**Pros:**
- Clear completion signal (button disabled or disappears)
- Easier to control and monitor
- Less likely to trigger anti-bot measures

**Cons:**
- Requires finding correct button selector
- May have rate limiting on button clicks
- Need to handle button state changes

**Implementation:**
```javascript
let loadMoreVisible = true;
let clickCount = 0;
const MAX_CLICKS = 100; // Safety limit

while (loadMoreVisible && clickCount < MAX_CLICKS) {
  // Find "Load More" button
  const loadMoreBtn = await page.$('button:has-text("Load More")');
  if (!loadMoreBtn) {
    console.log('[scraper] No "Load More" button found');
    break;
  }

  // Check if button is disabled
  const isDisabled = await loadMoreBtn.evaluate(btn => btn.disabled);
  if (isDisabled) {
    console.log('[scraper] "Load More" button disabled');
    break;
  }

  // Click button
  await loadMoreBtn.click();
  clickCount++;

  // Wait for new content to load
  await page.waitForTimeout(2000); // 2 second delay (polite)
}
```
</details>

<details>
<summary><b>Option C: API Endpoint</b> (Best - if available)</summary>

**Pros:**
- Most efficient and reliable
- No UI rendering overhead
- Can control pagination with query params
- Easier to handle errors and retries

**Cons:**
- Requires authentication token
- May have rate limiting
- Need to reverse-engineer API structure

**Implementation:**
```javascript
// Extract auth token from browser cookies
const cookies = await context.cookies();
const sessionCookie = cookies.find(c => c.name === 'session');

// Make direct API calls
let page = 1;
let hasMore = true;

while (hasMore) {
  const response = await page.context().request.get({
    url: `https://business.hipages.com.au/api/leads?page=${page}&limit=50`,
    headers: {
      'Authorization': `Bearer ${sessionCookie.value}`,
      'Content-Type': 'application/json'
    }
  });

  const data = await response.json();
  if (data.leads.length === 0) {
    hasMore = false;
  } else {
    allLeads.push(...data.leads);
    page++;
  }
}
```
</details>

/**
 * Scroll/load all available leads on the page
 * Handles infinite scroll or "Load More" buttons
 */
async function loadAllLeads(page) {
  console.log('[scraper] Loading all historical leads...');

  let previousLeadCount = 0;
  let stableIterations = 0;
  const MAX_STABLE_ITERATIONS = 3; // Stop if no new leads after 3 attempts
  const MAX_ITERATIONS = 50; // Safety limit to prevent infinite loop

  for (let i = 0; i < MAX_ITERATIONS; i++) {
    // Method 1: Try "Load More" button first
    const loadMoreBtn = await page.$('button:has-text("Load More"), button:has-text("Show more"), button:has-text("Load older")');
    if (loadMoreBtn) {
      const isDisabled = await loadMoreBtn.evaluate(btn => btn.disabled);
      if (!isDisabled) {
        console.log(`[scraper] Clicking "Load More" button (iteration ${i + 1})`);
        await loadMoreBtn.click();
        await page.waitForTimeout(2000); // Polite delay
        continue;
      }
    }

    // Method 2: Infinite scroll fallback
    await page.evaluate(() => {
      window.scrollTo(0, document.body.scrollHeight);
    });

    // Wait for content to load
    await page.waitForTimeout(2000); // 2 second polite delay

    // Check if new leads loaded by counting lead containers
    const currentLeadCount = await page.evaluate(() => {
      return document.querySelectorAll('[data-testid*="lead"], .lead-card, [class*="lead"]').length;
    });

    console.log(`[scraper] Iteration ${i + 1}: ${currentLeadCount} leads on page`);

    if (currentLeadCount === previousLeadCount) {
      stableIterations++;
      if (stableIterations >= MAX_STABLE_ITERATIONS) {
        console.log('[scraper] No new leads loaded, stopping pagination');
        break;
      }
    } else {
      stableIterations = 0; // Reset if new leads found
      previousLeadCount = currentLeadCount;
    }
  }

  console.log(`[scraper] Pagination complete: ${previousLeadCount} total leads on page`);
}
```

**What to avoid:**
- Don't use aggressive scroll speeds (can trigger bot detection)
- Don't skip delays between requests (violates polite scraping)
- Don't assume infinite scroll works (implement fallback for "Load More" buttons)

**Why:**
Hipages likely uses infinite scroll or "Load More" buttons. The hybrid approach handles both cases. 2-second delays are polite and won't trigger rate limiting. Safety limits prevent infinite loops if page behaves unexpectedly.

/**
 * Log scrape progress for monitoring
 * Helps track pagination advancement and detect issues
 */
async function logScrapeProgress(metadata) {
  try {
    const insertStmt = `
      INSERT INTO hipages_scrape_log (
        scrape_id,
        started_at,
        completed_at,
        leads_found,
        leads_saved,
        leads_updated,
        pages_scraped,
        status,
        error_message
      ) VALUES ($1, $2, $3, $4, $5, $6, $7, $8, $9)
    `;

    const values = [
      metadata.scrape_id,
      metadata.started_at,
      metadata.completed_at || null,
      metadata.leads_found || 0,
      metadata.leads_saved || 0,
      metadata.leads_updated || 0,
      metadata.pages_scraped || 1,
      metadata.status || 'IN_PROGRESS',
      metadata.error_message || null
    ];

    await pool.query(insertStmt, values);
    console.log(`[db-writer] Scrape progress logged: ${metadata.status}`);
  } catch (error) {
    console.error('[db-writer] Error logging scrape progress:', error);
    // Don't throw - logging failures shouldn't stop scraping
  }
}
```

  leads_found INTEGER NOT NULL DEFAULT 0,
  leads_saved INTEGER NOT NULL DEFAULT 0,

  error_message TEXT,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
