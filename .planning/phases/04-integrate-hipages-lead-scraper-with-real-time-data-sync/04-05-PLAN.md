<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| .env file → hipages-scraper container | Environment variables contain credentials |
| hipages-scraper → hipages.com.au | External website authentication |
| hipages-scraper → PostgreSQL | Direct database write (internal network) |
| Host → hipages-scraper container | Docker volume mount for output |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-4-24 | Information Disclosure | .env file credentials | mitigate | File permissions 600 (owner read/write only). Not committed to git (.gitignore). |
| T-4-25 | Spoofing | hipages.com.au credentials | mitigate | Stored in env var, not in code. Rotatable without code change. Consider credential rotation every 90 days. |
| T-4-26 | Denial of Service | Scraper resource consumption | mitigate | Docker resource limits (CPU: 1, memory: 1G). File lock prevents concurrent runs. Cron limits to 4x/day. |
| T-4-27 | Tampering | Database write | accept | Internal network only (homelab_internal). No public exposure. Scraper is trusted service. |
| T-4-28 | Information Disclosure | Output volume | accept | Contains screenshots and logs. No PII beyond what hipages provides. Mount point /app/output only. |
| T-4-29 | Elevation of Privilege | Container breakout | mitigate | Non-root user (scraper). Minimal system packages. No privileged mode. |
</threat_model>
