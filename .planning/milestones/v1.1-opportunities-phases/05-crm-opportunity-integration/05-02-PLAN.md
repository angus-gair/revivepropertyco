# Plan: UI Integration and E2E Tests (05-02-PLAN.md)

This plan implements the backend improvements to preserve all Hipages lead data inside Twenty CRM (via a linked Note), the frontend "Promote to CRM" UI actions, status badge rendering, and Playwright integration tests.

## Proposed Changes

### CRM Client & API Extension
#### [T-1] Update `server/lib/twenty-client.cjs`
- Add `createNote(noteData)` helper using a GraphQL mutation `createOneNote`.
- This mutation creates a Note and links it to target records (like Opportunities or People) via `noteTargets`.

#### [A-1] Update API Endpoint in `server/api/hipages.cjs`
- Update `POST /api/hipages/leads/:id/promote-opportunity`.
- When promoting a lead, format all lead data (description, location, credits, status, contact status, posted date, hipages ID) as a clean Markdown summary.
- Call `twentyClient.createNote` to save this markdown summary inside Twenty CRM linked to the newly created Opportunity.

### Frontend Dashboard UI
#### [U-1] Update `pages/admin/HipagesLeadsNoAuthPage.tsx`
- Import `TrendingUp` or `ExternalLink` from `lucide-react`.
- Add a "Promote to CRM" action button next to leads in the table and in the details modal.
- Disable the button and show a spinner during active API call.
- Verify both `lead.synced_to_crm` and `lead.syncedToCrm` mapping to ensure consistent rendering.
- If `synced_to_crm` is set, render an "Opportunity Created" badge linking directly to Twenty CRM Opportunities list (`https://crm.revivepropertyco.au/objects/opportunities`).

### E2E Testing
#### [E-1] Create `tests/hipages-crm-opportunity.spec.ts`
- Mock the `POST /api/hipages/leads/:id/promote-opportunity` endpoint to return success.
- Mock the `GET /api/hipages/noauth/leads` endpoint with test cases (synced and unsynced).
- Render the leads page and trigger the promotion action.
- Assert that the "Promote to CRM" button transforms into the "Opportunity Created" badge and renders the correct hyperlink.

## Verification Plan

### Automated Tests
- Run Playwright E2E test suite:
  ```bash
  npx playwright test tests/hipages-crm-opportunity.spec.ts
  ```

### Manual Verification
- Trigger promotion on the local dashboard and verify that the backend logs note creation successfully.
