<threat_model>
### Security Threat Model

- **Threat: Unauthorized Trigger Attacks (High Severity)**
  - *Description*: An unauthenticated attacker could repeatedly trigger manual scraper runs, overloading external hipages.com.au servers or causing denial of service (DoS) locally.
  - *Mitigation*: Ensure the `/api/hp-businesses/scrape/trigger` endpoint is protected by the `authenticateToken` middleware, requiring a valid administrator JWT bearer token.
- **Threat: Database Connection Exhaustion (Medium Severity)**
  - *Description*: Maintaining a persistent connection for PostgreSQL `LISTEN` in the scheduler daemon and backend API could leak connections or exhaust the connection pool.
  - *Mitigation*: The backend listener and scheduler use dedicated, isolated client connections instead of the general query pool. The scheduler reconnects gracefully (waiting 5 seconds) if connection drops.
- **Threat: Scraper Blocking & IP Bans (High Severity)**
  - *Description*: Scrapes executing too fast are easily detected as bot traffic, leading to permanent IP bans of the homelab system by hipages bot protection.
  - *Mitigation*: Strict enforcement of random page transition pauses (3-7 seconds) and category delays (10 seconds) to simulate organic human browsing behavior.
</threat_model>
