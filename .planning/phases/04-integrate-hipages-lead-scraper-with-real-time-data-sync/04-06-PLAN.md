   - CONTAINER_NAME="revive-hipages-scraper"
   - DB_NAME="revivepropertyco"
   - DB_USER="homelab"

3. Function check_container_health():
   - docker ps | grep $CONTAINER_NAME
   - docker inspect --format='{{.State.Health.Status}}' $CONTAINER_NAME
   - Return 0 if healthy, 1 if not

   - Query database: SELECT COUNT(*), MAX(scraped_at) FROM hipages_leads WHERE scraped_at > NOW() - INTERVAL '24 hours'

   - docker compose logs --tail=100 hipages-scraper | grep -q "Scrape completed"
   - Return 0 if found, 1 if not

   - curl -s -o /dev/null -w "%{http_code}" https://revivepropertyco.au/admin/hipages-leads
   - Return 0 if 200, 1 if not

7. Main script that:
   - Runs all checks
   - Prints status for each check
   - Exits with code 0 if all pass, 1 if any fail

8. Make executable: chmod +x verify-production-deployment.sh

Use bash script patterns from existing test scripts in project (grep for similar verification patterns).

| T-4-33 | Spoofing | Fake health check results | mitigate | Script checks multiple sources (docker ps, database, logs, HTTP). Hard to fake all. |
| T-4-34 | Denial of Service | Resource exhaustion during cutover | mitigate | Resource limits on new container (CPU: 1, memory: 1G). Old containers stopped before new ones consume resources. |
