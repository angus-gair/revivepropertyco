# Revive Property Co. - Architectural Maintenance Protocol

A high-fidelity industrial dashboard for Revive Property Co. featuring the AI-powered concierge "Riv" and a bespoke architectural intake protocol for Canberra property services.

**Live URL:** [https://revivepropertyco.au](https://revivepropertyco.au)

## Engineered Features

- **Architectural Intake Protocol**: A refined 2-step booking flow designed for precision service calibration and scheduling.
- **AI Concierge "Riv"**: High-speed specialized assistant providing instant quotes and localized service intelligence.
- **Universal TeleQuote**: Zero-friction WebRTC-based video assessment protocol (no apps/accounts required).
- **Industrial Dashboard**: High-density grid-driven UI with real-time technical manifest synchronization.
- **Investment Framework**: Dynamic pricing calibration based on selected service modules.

## AI Infrastructure (Z.AI)

The concierge "Riv" is powered by the **Z.AI Dedicated Coding PAAS**, optimized for industrial precision and ultra-fast response times.

- **Model**: `glm-4.7` (Specialized Reasoning & Coding)
- **Performance**: Zero-thinking protocol enabled for <2500ms handshakes.
- **Base URL**: `https://api.z.ai/api/coding/paas/v4/chat/completions`
- **Location Intelligence**: Calibrated for Canberra ACT and surrounding regions.

## Local Development

**Prerequisites:** Node.js 20+

1. **Install Dependencies**:
   ```bash
   npm install
   ```
2. **Launch Portal**:
   ```bash
   npm run dev
   ```

## Technical Specification

- **Frontend**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 (Local PostCSS Build)
- **Backend**: Node.js + Express
- **Persistence**: PostgreSQL
- **Deployment**: Dockerized production stack with automated health monitoring.
