```javascript
async function transaction(callback) {
  const client = await pool.connect();
  try {
    await client.query('BEGIN');
    const result = await callback(client);
    await client.query('COMMIT');
    return result;
  } catch (error) {
    await client.query('ROLLBACK');
    throw error;
  } finally {
    client.release();
  }
}
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin dashboard → Backend API | JWT authentication required |
| Backend API → PostgreSQL | Parameterized queries |
| PostgreSQL NOTIFY → Backend | Internal notification channel |
| Backend → WebSocket clients | Authenticated socket connections |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-4-12 | Spoofing | /api/hipages/* endpoints | mitigate | authenticateToken middleware on all routes. Verify JWT signature and expiration. req.user.userId available. |
| T-4-13 | Tampering | Accept lead endpoint | mitigate | Transactional write (BEGIN → INSERT leads → UPDATE hipages_leads → COMMIT). Rollback on error. |
| T-4-14 | Information Disclosure | hipages lead data | mitigate | Only authenticated admins can access. Audit log all lead views (add to audit_log table). |
| T-4-15 | Denial of Service | WebSocket broadcast | mitigate | Rate limit socket connections. Don't store large payloads in memory. |
| T-4-16 | Spoofing | CSRF on accept endpoint | mitigate | JWT in Authorization header (not cookie). SameSite not applicable for token-based auth. |
| T-4-17 | Tampering | SQL injection in filters | mitigate | All queries use parameterized placeholders. No string concatenation in WHERE clause building. |
</threat_model>
