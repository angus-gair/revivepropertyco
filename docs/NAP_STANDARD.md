## Rules

1. **No variations** — Use EXACTLY as written above
2. **No abbreviations** — "Street" not "St", "Australian Capital Territory" not "ACT" in full address
3. **Consistent formatting** — Phone format: `02 8201 3710` (space after area code)
4. **URL format** — Always include `https://` and NO trailing slash
5. **Structured data exception** — JSON-LD uses E.164 international format: `+61282013710`
