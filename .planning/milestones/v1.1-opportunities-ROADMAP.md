## Phase Details

### Phase 5: CRM Opportunity Integration

**Goal**: Enable promoting scraped Hipages leads directly to Twenty CRM Opportunities from the admin dashboard, preserving all relevant data.
**Depends on**: Milestone v1.0-mvp (Phase 4 completed)
**Requirements**: OPP-01, OPP-02, OPP-03, OPP-04, OPP-05, OPP-06, OPP-07, OPP-08, OPP-09, OPP-10
**Success Criteria** (what must be TRUE):
  1. Backend API promoting Hipages leads successfully matches or creates `Person` and creates `Opportunity` objects in Twenty CRM.
  2. Map all metadata (posted date, location, description, value/credits, category) into standard Twenty Opportunity fields.
  3. UI Promote button works on `/contractors/hp-leads` page, updating to show promotion status and direct link.
  4. Playwright E2E integration test suite validates successful lead promotion.
