<threat_model>
### Security Threat Model

- **Threat: CSRF & Unauthorized State Modification (Medium Severity)**
  - *Description*: Attackers could trick an admin into executing actions (like archiving businesses or triggering scrape runs) on their behalf if requests rely on ambient credentials.
  - *Mitigation*: The React application retrieves the administrator token from `localStorage` (`revive_admin_token`) and explicitly attaches it as an `Authorization` header (`Bearer <token>`) on all state-modifying requests, ensuring token verification is strictly required server-side.
- **Threat: Frontend Token Storage Exposure (Low Severity)**
  - *Description*: Storing administrative tokens in local storage exposes them to XSS access.
  - *Mitigation*: Ensure standard React sanitization is active. All rendered strings are escaped to prevent injection.
</threat_model>
